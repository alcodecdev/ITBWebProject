# GTR - Gestor de Movilidad Ganadera

Este proyecto consiste en una aplicación web diseñada para la gestión y 
validación de guías de transporte ganadero en tiempo real. 
Su función principal es actuar como un puente inteligente entre el operario de campo y 
los servicios oficiales.

La aplicación permite centralizar la autenticación y el alta de movimientos de animales, 
garantizando que los datos introducidos 
cumplan con los requisitos legales y de negocio antes de ser procesados por la administración.

---

## Tecnología Principal

El núcleo del proyecto ha sido desarrollado utilizando **Vue.js**, aprovechando su arquitectura moderna para ofrecer una herramienta de alto rendimiento y fácil mantenimiento.

### ¿Por qué Vue.js?

#### Reactividad Eficiente
Se utiliza el sistema de reactividad de Vue para gestionar el estado de los formularios y la respuesta de la API de forma instantánea, mejorando la experiencia del usuario sin recargas de página.

#### Single Page Application
La navegación entre el login y el panel principal es fluida y rápida, algo crítico para el trabajo en movilidad.

#### Arquitectura Basada en Componentes
Permite una separación clara entre la lógica de comunicación y la interfaz visual, facilitando futuras actualizaciones del sistema.

#### Rendimiento Optimizado
Gracias a su ligereza, la aplicación garantiza tiempos de carga mínimos, factor determinante para su uso en entornos rurales con conectividad limitada.
